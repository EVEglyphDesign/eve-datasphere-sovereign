INT — Universal Interaction Journal

IJTEL

26 fields · 4 key · 1 foreign keys · sourced from EVEglyphDesign canonical structure. Shapes follow standard call-detail and SIP session practice; not a vendor table.

Telephony extension of the interaction journal. Keyed on the interaction line, so a voice interaction carries its call detail without every other channel inheriting empty columns. Numbers are held as salted hashes, never in the clear: a call record is personal data and the mirror is not a wiretap.
