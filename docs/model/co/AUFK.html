CO — Controlling

AUFK

49 fields · 2 key · 19 foreign keys · sourced from leanx.eu

Order master data — the header record shared by every SAP order type (internal order, maintenance order, service order, WBS-linked order): order number, order type, controlling area, responsible/settlement cost center, status, and settlement cost element. This is the SAP analogue the CDK repair order keys on directly (AUFK-AUFNR).
