HR Master Record: Infotype 0002 (Personal Data) — the employee's personal identity data: legal name components (last/first/birth/nickname/middle name), title and name affixes, gender, date and place of birth, nationality (up to three), marital status and date, number of children, communication language, religious denomination, and personnel ID number, keyed by personnel number under the same validity-interval pattern as PA0001 Organizational Assignment. SAP's real table carries additional Japan-localization name-script fields (Katakana/Romaji); this definition carries the complete field list as sourced. This infotype is personal data in the strict sense — it holds an identifiable employee's legal identity, birth, and family-status details — and any mirrored copy must be handled under consent-scoped access controls.
