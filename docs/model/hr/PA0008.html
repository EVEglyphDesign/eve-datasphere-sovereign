HR Master Record: Infotype 0008 (Basic Pay) — the employee's compensation record: pay scale type/area/group/level, annual salary, and up to 40 repeating wage-type slots (LGA01-LGA40, each with its amount BET_nn, number ANZ_nn, unit EIN_nn, operation indicator OPK_nn, and indirect-valuation flag IND_nn), keyed by personnel number under the same validity-interval pattern as PA0001 Organizational Assignment. SAP's real table carries 40 repeating wage-type slot groups (roughly 190 fields in total); this definition is scoped to the full key, all organizational/pay-scale reference fields, and the first 8 wage-type slots (LGA01-LGA08 and their BET/ANZ/EIN/OPK/IND companions) as representative of the repeating pattern — it does not silently truncate, and a crosswalk needing slots 9-40 should extend the same repeating five-field pattern. This infotype is personal data — it discloses an identifiable employee's actual pay — and any mirrored copy must be handled under consent-scoped access controls.
