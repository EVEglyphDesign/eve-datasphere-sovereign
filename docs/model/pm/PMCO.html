PM — Plant Maintenance

PMCO

29 fields · 9 key · 1 foreign keys · sourced from leanx.eu

Cost structure of maintenance order — the CO totals-record table holding period-bucketed planned/actual/commitment cost values (WRT00–WRT16, one slot per posting period plus adjustment/total periods) for a maintenance order object (OBJNR), broken out by value type, fiscal year, version, and category. This is the cost side of order settlement/reporting that reconciles against PMCO's controlling-area currency (COCUR).
