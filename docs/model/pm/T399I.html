Planning Plant Parameters — customizing table holding control parameters per maintenance planning plant (IWERK): the default current-date rule for PM order start/end dates and the default units of measure for normal duration and work. Referenced by IWERK on EQUZ (equipment time-segment planning plant), IFLOT (functional location planning plant) and AFIH (maintenance order header planning plant), which all designate the plant responsible for planning that object or order.
