ANLH

8 fields · 3 key · 2 foreign keys · sourced from leanx.eu

Main Asset Number — the header record for a main asset number (company code plus main number, independent of subnumber), carrying the last subnumber and line-item counters assigned under it. ANLA's ANLN1 and the check tables of ANLB/ANLC/ANLZ/ANEK/ANEP/ANEA all resolve through this table, making it the root anchor for every asset-subledger row that must ultimately tie back to the same BUKRS/ANLN1 combination posted in ACDOCA/BSEG asset line items.
