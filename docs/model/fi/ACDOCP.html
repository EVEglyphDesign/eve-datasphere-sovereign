FI — Financial Accounting

ACDOCP

52 fields · 4 key · 21 foreign keys · sourced from saplearners.com

Plan Data Line Items — the planning companion to the ACDOCA actuals spine already defined in this repo, structurally mirroring ACDOCA so plan and actual can be compared line-for-line. Stores period-based planning data (General Ledger Planning, Cost Center Planning, Profit Center Planning, and other CO planning) in the same universal-journal shape as ACDOCA/ACDOCU. SAP's real table carries 203 fields (source: saplearners.com field listing, corroborated by SAP Community and Eursap documentation on S/4HANA Group Reporting architecture); leanx.eu has no page for this HANA-era table, so this definition is scoped to the key, ledger, organizational (company code, cost/profit center, functional area, business area, controlling area, segment), account, amount (per-currency value fields), quantity, date, and version/category fields a plan-vs-actual crosswalk consumes — never silently truncated, but not carrying the full CO-PA and industry-specific (fashion/aviation/oil) characteristic block.
