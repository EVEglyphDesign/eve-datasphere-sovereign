RSDCUBE

50 fields · 2 key · 2 foreign keys · sourced from leanx.eu

Directory of InfoCubes / InfoProvider — the BW metadata catalog row for every InfoCube and generic InfoProvider, keyed by InfoCube technical name (INFOCUBE) and object version (OBJVERS). Carries the InfoArea assignment, the Business-Content namespace/release stamp (BWAPPL/CONTREL/CONTTIMESTMP, distinguishing SAP-delivered from customer-created InfoCubes), the InfoProvider type/subtype (CUBETYPE/CUBESUBTYPE: BasicCube, Aggregate, RemoteCube, VirtualProvider, HANA-model-backed, etc.), the higher-level provider link (SUPERPROV/SUPERTLOGO) for MultiProviders and aggregates, real-time/direct-update mode (TRANSACT), source-system and InfoSource links for remote/virtual providers, and the size-category/data-class settings governing the physical fact and dimension tables generated for the cube. RSDCUBE is the master directory the mirror's runtime discovery walks to enumerate InfoCube-backed generated fact (/BIC/F*) and dimension (/BIC/D*) tables in a customer system; the /BI0/* and /BIC/A* generated master-data namespaces this InfoCube's dimensions reference are documented separately in bw/tables/GENERATED-PATTERNS.yaml. SAP's real RSDCUBE table carries roughly 115 fields, almost all of which are boolean/enum behavior-control switches for query optimization, caching, aggregation, and BWA/HANA acceleration (SV*, CACHE*, AGGR*, PART*); this definition is scoped to the identity, namespace, provider-type, hierarchy, and physical-storage-class fields the model consumes — no field has been silently dropped from those categories, and the full switch-field list is in the source below.
