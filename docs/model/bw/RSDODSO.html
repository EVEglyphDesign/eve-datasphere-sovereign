RSDODSO

49 fields · 2 key · 1 foreign keys · sourced from leanx.eu

Directory of all DataStores — the BW metadata catalog row for every DataStore Object (DSO, formerly ODS object), keyed by DSO technical name (ODSOBJECT) and object version (OBJVERS). Carries the InfoArea assignment, Business-Content namespace/release stamp (BWAPPL/CONTREL/CONTTIMESTMP, distinguishing SAP-delivered from customer-created DSOs), the DSO type (ODSOTYPE: standard, write-optimized, direct-update), activation/processing automation flags (AUTOACTIVATEFL, AUTOPROCESSFL), SAP HANA-optimization and delta-consistency flags, and the size-category/data-class settings for the active-data and activation-queue tables. RSDODSO is the master directory the mirror's runtime discovery walks to enumerate which /BIC/A* (active data), /BIC/B* (before-image/change log), and /BIC/00* (activation queue) generated tables exist per DSO in a given customer system — see bw/tables/GENERATED-PATTERNS.yaml for how those generated tables are resolved rather than statically defined.
