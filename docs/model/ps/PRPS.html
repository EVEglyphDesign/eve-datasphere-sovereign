PRPS

86 fields · 2 key · 45 foreign keys · sourced from leanx.eu

WBS (Work Breakdown Structure) Element Master Data — one row per WBS element (PSPNR), the cost object that appears on ACDOCA as PS_PSP_PNR. Tie explicitly: fi/tables/ACDOCA.yaml carries a PS_PSP_PNR field with check_table PRPS and a foreign_keys entry resolving PS_PSP_PNR -> PRPS.PSPNR — every Universal Journal line item account-assigned to a WBS element resolves back to exactly one row in this table. PRPS carries the external WBS identifier (POSID) and short text, the parent project link (PSPHI -> PROJ.PSPNR), hierarchy level (STUFE), organizational assignment (company code, business area, controlling area, profit center, plant), the account-assignment/billing/planning indicator flags that determine whether the element can receive postings, costing-sheet and overhead-key links, responsible/requesting cost center links, and the object number (OBJNR) that ties this WBS element into the shared CO/status-management object-number space. SAP's real PRPS table carries roughly 106 fields, including Joint Venture Accounting fields (VNAME/RECID/ETYPE/OTYPE/JIBCL/JIBSA), production-lot fields (VLPSP/VLPKZ/SORT1-3), and generic-project-planning GUID fields (CGPL_*); this definition is scoped to the key, cost-object, organizational, hierarchy, and account-assignment-control fields the model consumes — no field has been silently dropped from those categories.
