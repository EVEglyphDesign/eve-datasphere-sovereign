EXT — Societal Effect Extension

ACDOCX

42 fields · 7 key · 7 foreign keys · sourced from EVEglyphDesign extension. Not an SAP structure. Keyed on ACDOCA; ACDOCA is unchanged.

Universal Journal societal effect line. The extension at the edge of ACDOCA: for one accounting document line, zero or more effect lines recording what that money did in the world. The key is ACDOCA's own key plus an effect item counter, so an effect line cannot exist without a posting behind it and the financial line is never modified. A ledger that records only the amount records half the transaction.
