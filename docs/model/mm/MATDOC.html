MATDOC

51 fields · 9 key · 20 foreign keys · sourced from www.s4hd.com

Material Document Segment (S/4HANA universal material-movement table) — the S/4HANA replacement for the classic ECC pairing of MKPF (material document header) and MSEG (material document item). MATDOC supersedes MKPF/MSEG outright: a customer running classic ECC mirrors MKPF/MSEG, while a customer on S/4HANA mirrors MATDOC — the model must read both to cover the MM inventory-movement lane across a customer's install base, the exact same duality FAGLFLEXA vs ACDOCA covers on the FI side (a customer running classic ECC mirrors FAGLFLEXA; a customer on S/4HANA mirrors ACDOCA). Structurally MATDOC is not keyed by MBLNR/MJAHR/ZEILE the way MSEG is — those remain present only as non-key legacy-compatibility reference fields — instead each row is keyed by a split GUID (KEY1 through KEY6) plus MANDT, RECORD_TYPE, and HEADER_COUNTER, reflecting MATDOC's role as a wide semantic-flattened table that carries stock-characteristic dimensions (material, plant, storage location, batch, special-stock indicators) directly on each movement row rather than requiring a join back to master data. SAP's real table carries 300+ fields including CWM parallel-unit-of-measure fields, EWM warehouse-document linkage, retail/fashion segmentation, and joint-venture accounting extensions; this definition is scoped to the split-GUID key, the legacy MBLNR/MJAHR/ZEILE compatibility fields, and the core business fields a downstream MM/FI crosswalk consumes (material, plant, storage location, batch, movement type, quantities, amounts, dates, and the account-assignment fields — cost center, order, WBS, asset, G/L account — that hand off to ACDOCA) — no fewer than 25 fields, per the wide-table rule.
