CAWN

29 fields · 4 key · 5 foreign keys · sourced from leanx.eu

Characteristic values — the predefined/allowed-value list for a characteristic defined in CABN, including value texts, floating-point ranges, and tolerances. Where AUSP records what value was actually assigned to an object, CAWN records what values were legal to assign in the first place. SAP's real CAWN carries all its fields; this definition carries the table complete.
