Telephone Numbers (Business Address Services) — the per-communication-type child of ADRC holding phone numbers for a given ADDRNUMBER, one of the sibling tables (with ADR3 fax, ADR6 e-mail) that ADRC's DEFLT_COMM/FLAGCOMM2 flags point at. SAP's real ADR2 carries all its fields; this definition carries the table complete, as it is a small check/detail table.
