DD01T

5 fields · 2 key · 1 foreign keys · sourced from leanx.eu

Domain texts — the language-dependent short description for every domain in DD01L. Small text-carrier table, carried complete. It matters to the sovereign mirror for the same reason all *T tables matter here: a crosswalk claim that cites a domain by name is only as verifiable as the label the customer's own dictionary attaches to it, and DD01T is that label, keyed by language so the mirror can validate in the customer's working language rather than assume English.
