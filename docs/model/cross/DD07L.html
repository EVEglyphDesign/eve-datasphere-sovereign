Values for the domains — the fixed-value list (single values and value ranges) attached to a domain in DD01L when VALEXI is set. This is the table the mirror checks a crosswalk's claimed enumeration against: if a crosswalk asserts that a status field only ever takes certain codes, DD07L is where that claim gets settled against the customer's own configured domain values rather than an assumption baked into the crosswalk.
